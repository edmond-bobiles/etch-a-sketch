# Etch-a-Sketch

A browser-based sketch pad built for [The Odin Project](https://www.theodinproject.com/). Move the pointer across the grid to color squares blue.

## Getting started

Clone the repository and open `index.html` in a modern browser. No build step is required. Tailwind CSS is loaded from a CDN, so an internet connection is needed for styling.

```sh
git clone https://github.com/edmond-bobiles/etch-a-sketch.git
cd etch-a-sketch
```

## Usage

The initial grid is 16 by 16 squares. Select **New Grid**, enter a size from 1 to 100, and select **Accept** to create a fresh square grid. Select **Cancel** to keep the current grid.

## Built with

HTML, JavaScript, and Tailwind CSS.
